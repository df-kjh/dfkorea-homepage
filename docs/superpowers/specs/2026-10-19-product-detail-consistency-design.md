# 제품 상세 통일 보완

## 사용자 요구

몰드바와 다른 상세가 다른 구성으로 보인다는 피드백을 반영한다. 승인된 몰드바를 기준으로 공통 섹션·제목·사진 배치를 일관되게 적용하고 모든 등록 제품에 제품 유형별 설치 예시를 제공한다. 네모 치수 도식과 제어 동작도 공통 컴포넌트로 고친다. 별도 브랜치에서 작업 후 로컬 main에 병합한다. 이번 요청에 운영 배포는 없다.

## 공통 구성

히어로 → 핵심 사양 → 제품 소개·실물 사진·특징 → 제품 구조·원본 확대 → 설치 예시 → 등록된 제어 옵션 → 규격 → 기존 기술 자료 → 상세 사양 → 문의를 유지한다. 몰드바의 승인된 기본 제목을 공통 기본값으로 사용하고, 제품명·사용 환경·실제 사진·사양은 각 제품을 따른다. 소개 제목의 ‘길을 따라’는 비선형 제품에 맞게 ‘공간에 맞게’로 조정할 수 있으며 동일한 제목 배치와 디자인을 유지한다. 사진이 한 장뿐이어도 구조 영역에서 해당 원본을 확인할 수 있게 한다. 없는 내부 부품·보이지 않는 각도·인증·성능을 만들어 내지 않는다.

기존 관리자 detailContent v1 계약·직접 편집·null 초기화·이미지 업로드·PC/모바일 미리보기·등록 사진 API 상대 주소 변환과 이전 견적/제품군/SEO/갤러리 동작을 보존한다. 승인된 명시적 관리자 override는 공통 기본값보다 우선한다. 새 제품은 기존 카테고리/치수로 검토한 유형 기본값을 쓰며, 알 수 없는 유형에도 설치 예시 영역이 빠지지 않게 기존 원본 이미지와 중립적 캡션으로 대체한다.

## 설치 이미지

실제 등록 사진을 참고하여 신규 AI 설치 예시를 유형별로 만든다. 기존 몰드바 이미지는 그대로 보존한다. PIPE 펜던트, 칠판, 가로등, 방습, COB, 원형, 다운라이트, 계단표시, 차량유도, 벽부, 크린룸, 일반/광폭 주차장 선형, 정사각 평판, 직사각 평판의 14개 신규 유형별 이미지를 사용한다. 서로 다른 제품 사진을 몰드바 사진으로 대체하지 않는다. 생성 이미지는 설치 영역의 공통 연출 캡션과 정확한 alt로 구분한다. 이전 사용자 주석에서 삭제한 히어로 이미지 안내 문구는 자동으로 되살리지 않는다. 관리자 명시적 이미지 캡션은 기존 v1 계약대로 우선한다. 이미지 생성 프롬프트/참고 사진/저장 위치는 로컬 작업 기록에 남기고 공개 manifest에는 개인 절대경로·전체 프롬프트·도구 원본 출력을 넣지 않는다.

공통 타입 `ProductApplicationProfile`: key, productIds, image {url,alt}, description. 에셋 경로 `/images/product-detail/applications/{key}-v1.png`. keys: pipe-pendant, classroom, street, moisture-proof, cob-retail, round-ceiling, downlight, stair-sign, parking-guidance, wall-light, cleanroom, parking-linear, panel-square, panel-linear. 모르는 신규 제품은 명시적 카테고리/치수 분류와 원본 대체로 처리하고 임의 성능 문구를 넣지 않는다.

## 제어 시뮬레이션

공통 `ControlSimulation`을 사용한다. 개별디밍은 여섯 위치 중 격등(1·3·5)의 세 제품만 켜지고 각자 서로 다른 위상으로 밝기가 연속 변한다. 나머지는 꺼짐을 유지한다. 그룹디밍은 한 줄의 세 제품이 같은 위상으로 동시에 밝기가 변한다. 발전기 비상과 배터리 비상(기존 데이터의 밧데리 비상 포함)은 탭 선택 시 꺼짐에서 시작하고 정확히 1000ms 후 밝게 켜져 계속 켜짐을 유지한다. 탭 재진입 시 처음부터 재생하고 탭 변경·unmount 시 타이머를 해제한다. 센서 동작은 기존 감지 개념을 유지하고 불필요한 고속 점멸을 추가하지 않는다. 감소된 동작 설정에서는 디밍을 정지된 대표 상태로 표시하며, 비상은 동일한 1초 전환을 부드러운 반복 없이 한 번만 보여준다. 자동 애니메이션의 일시정지/재생 또는 재시작을 접근 가능한 공통 컨트롤로 제공한다. 실제 제품 옵션에 없는 제어를 해당 제품의 지원 기능처럼 추가하지 않는다.

## 치수 도식

`DetailDimensions`에 `product: Product`를 전달한다. `dimensions.ts`에서 등록 문자열을 해석하고 공통 네모 외곽 범위 도식을 그린다. 측정선/보조선의 시작·끝은 네모의 대응 꼭짓점에 정확히 맞춘다. 선 끝에 닿지 않는 부동 라벨을 없애고 모든 치수에 mm를 표시한다. 도식은 실제 비율/형상/설치 도면이 아닌 치수 범위 안내로 명시한다.

세 숫자 x/*/×는 기존 순서의 길이·폭·높이를 보존한다. 원형의 240*62는 지름·높이로 표시하며 네모 도식은 외곽 범위일 뿐 원형 본체를 네모 본체로 설명하지 않는다. 여러 규격, 타공 정보, PIPE 길이 목록은 숫자를 추정해 합치지 말고 원 등록 문자열·명시적 여러 값으로 남긴다. 0/NaN/음수/알 수 없는 값은 치수로 생성하지 않는다. 관리자 dimensionImage는 우선한다.

## 검증

제어 위상/격등/한 줄 그룹, 비상 999ms 꺼짐·1000ms 켜짐·이후 상시·탭 재진입·타이머 해제·키보드·감소 동작을 검사한다. 치수 3D/원형/복수/타공/PIPE/잘못된 입력과 측정선 대응을 검사한다. 기존 25개 전부 설치 예시와 공통 섹션, 23개 제품군·원 ID·견적·관리자 우선순위를 확인한다. 각 이미지 파일 존재와 로딩을 확인한다. 로컬 PC/모바일 브라우저에서 실제 시간 경과 애니메이션과 도식, 설치 예시를 확인한다. products/admin/quote 메뉴 문서에 변경과 운영 미배포/연출 이미지 한계를 기록한다.
