# 검색 노출 개선 설계

## 목표

`https://dfkorealed.com`의 모든 공개 페이지, 제품 상세, 게시글 상세, 인증 분류 상세을 구글과 네이버가 안정적으로 발견하고 하나의 대표 URL로 색인할 수 있게 한다.

## 운영 점검 결과

- 구글 공개 검색에서 홈과 일부 제품 상세가 검색된다.
- 네이버 `site:dfkorealed.com` 검색에서 홈, 회사 소개, 제품 목록, 소식 목록, 인증 현황과 일부 제품 상세가 검색된다.
- `/robots.txt`, `/sitemap.xml`, `/rss.xml`은 HTTP 200으로 제공된다.
- 사이트맵은 공개 URL 141개(정적 5개, 제품 25개, 게시글 111개)를 포함하지만 인증 분류 상세 URL은 포함하지 않는다.
- 실제 운영 호스트는 `dfkorealed.com`이며 `www.dfkorealed.com`은 DNS 해석되지 않는다.
- robots.txt의 Sitemap, 전역 canonical, 정적 페이지와 상세 페이지의 canonical·Open Graph URL이 `www.dfkorealed.com`을 가리킨다.
- 회사 소개를 제외한 홈·인증 화면의 고유 SEO 정보는 브라우저에서만 바뀌어 초기 HTML에는 공통 제목과 설명이 남는다.
- 제품과 게시글 카드는 클릭 이벤트로만 이동해 목록 HTML에 상세 페이지로 향하는 실제 링크가 없다.
- 관리자와 Tailwind 테스트 페이지가 전역 `index, follow`를 상속한다.

## 설계

1. 대표 도메인을 `https://dfkorealed.com`으로 통일한다. 모든 canonical, Open Graph URL, 구조화 데이터, RSS, 사이트맵과 robots 안내가 같은 호스트를 사용한다.
2. 공개 정적 페이지는 Nuxt `useSeoMeta`와 `useHead`를 페이지 계층에서 사용해 제목, 설명, robots와 canonical을 서버 렌더링한다.
3. 제품·게시글 상세은 현재 서버 렌더링 구조를 유지하고 대표 도메인 설정만 바로잡는다. 인증 분류 상세은 경로 기반 제목, 설명과 canonical을 서버 렌더링한다.
4. 동적 사이트맵에 인증 분류 상세 URL을 추가한다. 제품, 게시글, 인증 데이터가 추가되거나 수정될 때 사이트맵 응답에도 즉시 반영된다.
5. 제품·게시글 카드에 실제 `href`를 가진 NuxtLink를 사용해 검색로봇과 키보드 사용자가 상세 페이지를 발견할 수 있게 한다.
6. 관리자와 테스트 페이지는 `noindex, nofollow`로 명시하고 robots.txt에서도 수집 대상에서 제외한다.
7. 운영 빌드와 운영 도메인 검증에서 공개 페이지의 canonical, 메타 태그, 사이트맵 URL 수와 상세 링크를 확인한다.

## 검색엔진 등록 전략

- 코드 배포 후 Google Search Console과 네이버 서치어드바이저에 `https://dfkorealed.com/sitemap.xml`을 제출한다.
- 홈, 제품 목록, 소식 목록, 대표 제품 상세, 최신 게시글 상세을 URL 검사 대상으로 삼아 재수집을 요청한다.
- 이후 월 1회 색인 제외 사유, 크롤링 오류, 중복 canonical과 구조화 데이터 오류를 확인한다.
- 사이트맵 제출은 발견과 수집을 돕지만 검색 결과 노출이나 순위를 보장하지 않는다. 제목과 본문 품질, 내부 링크, 외부 신뢰 신호를 계속 개선한다.

## 범위 제외

- 관리자 페이지와 개발용 Tailwind 테스트 페이지의 검색 노출
- 검색 광고, 백링크 구매, 순위 보장형 외부 서비스
- 검색엔진 계정 소유권 확인 토큰 자체 발급
