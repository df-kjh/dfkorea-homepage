# 물품 납품·MAS 중심 입찰 분류 설계

## 목적

전기공사업 자격이 없는 회사가 실제 참여 가능성이 높은 LED 조명 물품 납품과 다수공급자계약(MAS) 공고만 관리자 캘린더와 이메일에서 우선 확인하도록 한다. 기존 수집 데이터와 메일 발송 이력은 삭제하지 않는다.

## 동작 범위

- 나라장터 공사 공고는 저장하되 관리자 기본 조회와 메일 발송에서 제외한다.
- 나라장터 물품 공고는 `물품 납품`으로 분류한다.
- 나라장터 물품 공고 중 제목·설명·첨부파일명·계약방법에 `다수공급자계약` 또는 독립 단어 `MAS`가 있으면 `MAS`로 분류한다.
- 나라장터 면허제한정보를 같은 등록일시 범위로 수집하고, 공고번호·차수로 물품 공고에 결합한다.
- 물품 공고라도 면허제한명 또는 허용업종 목록에 `전기공사업`이 있으면 `공사 자격 필요`로 분류해 기본 조회와 메일에서 제외한다.
- K-apt 공식 분류코드 `codeClassifyType2`를 사용해 `02=공사`, `03=용역`, `04=물품`으로 정규화한다. 알 수 없는 코드는 `기타`로 유지한다.
- K-apt 공사·용역·기타와 나라장터 용역은 저장하되 기본 조회와 메일에서 제외한다.
- 기존 공고는 migration에서 업무구분과 K-apt 원본 분류코드를 기준으로 안전하게 backfill한다. 이후 다시 수집되면 최신 분류 규칙으로 갱신한다.

## 데이터 모델

`tenders`에 다음 두 컬럼을 추가한다.

- `opportunityType`: `GOODS_SUPPLY | MAS | EXCLUDED_CONSTRUCTION | EXCLUDED_NON_SUPPLY`
- `opportunityReasons`: 판정 근거 문자열 배열. 외부 API의 원본 인증정보나 서비스키는 포함하지 않는다.

`opportunityType`에는 조회·메일 선별을 위한 인덱스를 둔다. 기존 행과 신규 행 모두 두 컬럼이 항상 채워진다.

## 분류 우선순위

1. 업무구분이 공사이면 `EXCLUDED_CONSTRUCTION`.
2. 물품이면서 면허제한정보에 `전기공사업`이 있으면 `EXCLUDED_CONSTRUCTION`.
3. 물품이면서 MAS 표현이 있으면 `MAS`.
4. 나머지 물품은 `GOODS_SUPPLY`.
5. 용역·기타는 `EXCLUDED_NON_SUPPLY`.

제목에 `공사`가 들어가더라도 나라장터 업무구분이 물품이고 전기공사업 면허제한이 없으면 물품 납품으로 유지한다. 예: `시설개선공사 관급자재 구입(조명기구)`.

## API·관리자 화면

- 캘린더와 일자별 목록은 별도 요청 값이 없으면 `GOODS_SUPPLY`, `MAS`만 집계·반환한다.
- 응답 공고에는 `opportunityType`, `opportunityReasons`를 포함한다.
- 목록과 상세에 공통 배지를 사용한다.
  - `📦 물품 납품`
  - `🧾 MAS`
- 기존 공고 유형 필터는 유지한다. 공사·용역을 선택해도 기본 참여 가능 범위와 교집합이므로 결과가 없을 수 있다.
- 메일 제목·본문에서도 동일한 기회 유형과 판정 근거를 표시한다.

## 메일 선별

- 신규 메일 항목 생성 대상은 `GOODS_SUPPLY`, `MAS`만이다.
- 과거에 생성됐지만 아직 발송되지 않은 공사·비물품 메일 항목도 발송 후보에서 제외한다.
- 이미 발송된 이력, 수신 주소, 발송 시각, 재시도 상태는 변경하거나 삭제하지 않는다.

## MAS 경계

이번 변경의 MAS 알림은 공개 나라장터 공고에서 MAS 표현이 확인되는 구매공고를 대상으로 한다. 종합쇼핑몰 등록 품목·납품요구 정보는 시장정보이며 공개 입찰 기회와 동일하지 않으므로 이번 메일 대상에 섞지 않는다. 기존 MAS 계약업체에게만 전달되는 2단계 경쟁 제안요청은 공개 API만으로 모든 업체에 일반 공고처럼 제공된다고 가정하지 않는다.

## 비기능 요구사항

- 기존 DB 행을 삭제하지 않는다.
- API 키와 원본 인증정보를 응답·로그에 노출하지 않는다.
- 분류 변경은 실패 테스트를 먼저 작성하고 확인한 뒤 구현한다.
- DB 변경과 함께 `database-schema.md`를 갱신한다.
- 입찰 메뉴 변경과 함께 `docs/menus/tenders.md`를 갱신한다.
